About the pips

Star Citizen doesn't send its power state to outside apps, so the dashboard keeps its own copy. It stays accurate as long as you change power from here. If they drift apart, either tap SYNC to set the ship to the dashboard's levels (it presses the power keys for you, so keep the game focused), or tap MATCH and tap the pips to copy what the game shows without sending keys.

Sliders

Mining power and beam spacing are sent as mouse wheel notches. If a slider stops matching the game, tap Re-zero.
